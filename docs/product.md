# product.md — 自己紹介フレームワーク(make-i-n)

## 一言で
**人物データを1か所に書けば、場面ごとの自己紹介(Web ページ・16:9 スライド・PDF・PPTX)を
「並べ替え」だけで作れる**ローカル完結のフレームワーク。舞台裏では生成AI(Vertex AI GenMedia)で
画像・動画・音楽・ナレーションをその場で作り、ページに差し込める。

## 利用者と場面
| 場面(talk) | 構成の例 |
|---|---|
| 研究室同窓会 2026 | title → career-timeline → big-number → genmedia-studio → cta |
| 30秒自己紹介 | title(中央)→ big-number → cta |
| 登壇者紹介 | title → career-timeline(横軸)→ quote |
| 採用イベント | title → big-number → media-hero → cta(追加は YAML 1枚) |

## 原則
1. **単一ソース** — 経歴・数値・メッセージ・ナレーション原稿は profile にだけ書く。talk は参照と並べ方だけ。
2. **すべて日英** — テキストは `{ja, en}`。右上の「JP | EN」で即時切替。
3. **素材なしでも動く** — メディアが無いスロットはプレースホルダー。GenMedia で後から埋める。
4. **個人データはリポジトリに入れない** — `data/private/` は .gitignore。リポジトリにはサンプル(架空人物)だけ。
5. **認証情報をブラウザに出さない** — Vertex AI 呼び出しは 127.0.0.1 のローカルサーバーが代理する。

## 非目標
- 公開ホスティング・マルチユーザー(ローカルで作って発表・書き出す用途に限る)
- WYSIWYG エディタ(編集は YAML とプロンプト欄で行う)
